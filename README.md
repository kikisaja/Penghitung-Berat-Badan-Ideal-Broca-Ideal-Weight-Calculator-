# ⚖️ Ideal Weight Calculator (Rumus Broca)

Aplikasi kalkulator medis dasar interaktif berbasis JavaScript untuk mengestimasi berat badan ideal dan rentang sehat seseorang berdasarkan Rumus Broca.

---

## 🎯 Konsep Pembelajaran RPL / Pemrograman Web

1. **Conditional Formulas:**
   Mengaplikasikan rumus matematika berbeda berdasarkan variabel jenis kelamin (faktor pengurang 10% untuk pria dan 15% untuk wanita).
2. **Range Calculation & Logic Validation:**
   Menghitung rentang toleransi berat sehat (±10%) serta mengevaluasi status berat badan pengguna jika input berat opsional diisi.
3. **Form Radio Buttons & Event Handling:**
   Membaca dan merespons pilihan input dari elemen *radio button* secara interaktif.
